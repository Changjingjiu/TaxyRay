## DeepSeek真实文本诊断

仅向用户指定的官方 HTTPS 端点 `https://api.deepseek.com/chat/completions` 发送简短合成文本。模型 `deepseek-flash`，使用用户授权临时凭据；凭据没有写入源码、日志或APK，没有上传账本或图片。

- 原参数 `max_tokens=8`：HTTP200，finish_reason=length，正文0字符，8个输出token全为reasoning。
- 修正参数 `max_tokens=64`、`thinking.type=disabled`：HTTP200，finish_reason=stop，正文3字符，reasoning为0。
- 因此旧失败由默认思考耗尽输出预算引起，基础地址追加路径正确。应用请求参数已按此结果修正，限定官方DeepSeek主机发送专用thinking参数，并有请求体单元测试。
- 官方文档还要求指定具体工具调用时关闭思考模式，识别请求也已修正。本轮没有用真实小票完成图像识别验收。

依据：[DeepSeek首次调用](https://api-docs.deepseek.com/zh-cn/)、[创建对话接口](https://api-docs.deepseek.com/zh-cn/api/create-chat-completion/)。诊断不记录响应正文、reasoning或Key。
