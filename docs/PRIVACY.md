# TaxRay 隐私与网络边界

最后核对：2026-09-15。本文件描述当前源代码的行为，而不是第三方模型服务的隐私承诺。

## 哪些操作离线运行

手动录入、价税计算、账本查询、修改、删除、数据导出及分享卡生成都在设备内完成，不依赖 TaxRay 服务器。TaxRay 没有自建后端，也没有分析、广告、崩溃上报或远程配置 SDK。

AI 图片识别需要联网。选择图片本身不代表同意发送；用户明确触发识别后，客户端将压缩后的图片直接发送到用户配置的 API 服务。应用不会称这一步为“纯本地识别”。

## AI 服务能够收到什么

- 识别请求：用户选定的小票 JPEG、模型名称、提取提示词、工具定义，以及放在 Authorization 请求头内的 API Key。
- 连接测试：模型名称、简短的 `Reply OK.` 文本以及鉴权头。不发送账本或图片。测试成功只说明文本请求可用，不能证明模型支持图片、Tool Calling 或识别准确率。
- 图像会重新编码，移除原图片 EXIF 元数据。长边不超过 1920 像素，JPEG 实际字节数不超过 1,000,000（十进制 1 MB）。程序先采样解码，再调整方向、尺寸和压缩质量，避免先将高分辨率照片完整装入内存；原始图片读取上限为 40 MB。
- **图片上的可见内容仍会发送。** 移除 EXIF 并不等于遮挡会员号、银行卡信息、地址或人脸。提示词要求模型忽略无关字段，但不构成上传前脱敏。请先裁剪或遮挡不希望发送的内容。

设置自定义服务地址即选择了接收图片和 API Key 的服务方，包括中转服务。其日志、留存、训练使用、计费和所在地规则由该服务方决定。请自行确认服务方可信，并使用适当限额的密钥。项目不代理请求，也不能替第三方承诺零留存。

## AI 网络保护

请求只发往设置页显示的最终 HTTPS 地址。开启自动追加时补齐 `/chat/completions`，填写完整地址不会重复追加；关闭时按填写的路径请求。地址禁止用户名、密码、查询参数和 fragment；API Key 不出现在 URL、模型请求正文或导出文件中。TLS 使用平台正常证书验证，没有接受任意证书的代码。

HTTP 与 HTTPS 重定向均禁用，响应要求跳转时停止，不向跳转目标转发凭据。客户端不自动重试，避免在网络失败后重复发送小票或产生不可见的重复费用。连接、写入、读取及整次调用均设置超时；用户取消操作会取消 OkHttp Call 并关闭响应。响应上限为 2,000,000 字节，超过后停止读取。

应用仅向用户显示固定的状态说明和 HTTP 状态码，不回显第三方错误正文，不记录请求、响应、图片或密钥。没有网络日志拦截器。系统网络配置（如 VPN、代理或被管理的设备）仍会影响实际网络路径。

## GitHub 更新

设置中点击检查更新才访问公开仓库 `Changjingjiu/TaxLens`。检查和下载使用独立匿名 HTTP 客户端，不读取或发送账本、图片、API 配置、GitHub Token 或设备标识。GitHub 及其下载 CDN 会收到常规网络信息，例如 IP 地址与 User-Agent。没有后台定时检查或静默安装。

更新仅接受固定仓库的 HTTPS 发行资源，允许最多三次限定 GitHub CDN 域名的下载重定向。元数据、文件大小、下载时长均有限额；文件校验成功后由 Android 系统确认安装。安装来源权限只用于用户主动更新。更新暂存包放在应用私有缓存，系统可回收；完整设计见 [UPDATES.md](UPDATES.md)。

## API Key 如何存储

配置整体以 AES-256-GCM 加密后保存于应用私有 SharedPreferences。每次写入由 Android Keystore 加密提供方生成随机 12 字节 IV，使用 128 位鉴别标签并绑定应用和存储上下文。加密密钥在 Android Keystore 中生成，不由应用导出。硬件保护能力取决于设备，不能保证每台设备均有硬件安全模块。

配置和账本不参加 Android 自动云备份及设备转移备份。密钥不会进入 JSON/CSV 账本导出。`ApiSettings.toString()` 也会隐去配置内容。应用请求时必须短暂持有解密后的配置，JVM 字符串不能保证逐字节擦除；屏幕录制、设备失陷、调试注入或被用户分享的导出文件不在静态加密的保护范围内。

使用平台 Keystore 是对原技术文档的更新：[AndroidX Security 官方发布记录](https://developer.android.com/jetpack/androidx/releases/security) 已将 security-crypto API 标记为 deprecated，建议直接使用平台 API 和 Android Keystore；具体能力见 [Android Keystore 文档](https://developer.android.com/privacy-and-security/keystore)。本项目不引入旧版 EncryptedSharedPreferences 或明文回退路径。

解密失败时停止读取并提示清除 API 设置，不会静默把无法解密的配置当成可用凭据。清除配置时先删除 Keystore 密钥，再删除对应加密偏好；此操作不影响账本。

## 图片、账本与导出

压缩和识别在内存内进行，不保存识别原图作为账本附件。用户从相册选择的原图仍属于系统相册；清除应用数据不会删除该相册原图。调用系统相机可能由系统相机应用依照自身设置额外保留副本。

账本使用应用私有目录内的 Room/SQLite，**未使用 SQLCipher 等应用级数据库加密**。其保护依赖 Android 应用沙盒、设备加密与锁屏。导出的 JSON、CSV 和分享图片是用户可读取的明文，用户选择的接收应用也可读取这些内容。导出只包含消费记录及计算字段，不包含 API 配置。

JSON 与 CSV 的导出、导入采用相同上限：单文件5 MB（5,000,000字节）、10,000张账单、每单1000项。超过限额会报错，账本内容不会写入不可恢复的备份；当前不提供分卷功能，大账本超限时无法完整导出。备份内的派生税额与合计会由本地算法重新核对，冲突的账单ID会使整次导入回滚。

清空数据删除应用内账本并重置 API 加密密钥；共享临时文件也应随清理移除。此操作不能收回已导出的文件、已分享的图片、第三方 API 留存的请求或系统相册原图。闪存磨损均衡、系统快照与硬件实现使普通 Android 应用无法保证对存储介质进行取证级逐块覆写；因此“删除”不作这种保证。

## 模型结果的隔离

远程模块没有数据库写入能力。它只返回待复核的 `VisionReceipt` 和 `DraftItem`；用户确认后，核心计算器和数据库事务才执行入账。

解析器要求一次、一个、名称准确的 `parse_receipt_tax_items` 工具调用。截断结果、拒绝响应、多个调用、错误函数、畸形 JSON、重复对象键、过深嵌套、缺失必填字段、非正数金额、过量小数、未知分类枚举和超过 1000 项的输入会被拦截。金额直接读取 JSON 数值原文或十进制字符串交给 BigDecimal，不经过 Double。金额只接受普通十进制写法，科学计数法、货币符号和千分位分隔符会被拒绝。

模型返回结构化类别和短证据，客户端映射到 13%、9%、6% 估算档位；不再根据自由理由里的关键词判断不确定性。实际品名不完整、分类不明确或证据未对应时使用 13% 并给出具体操作提示。0% 必须有明确票面免税文字，单独 F、生鲜品名或“商超直采”不充分；程序检查的是模型返回的证据文字，并不能独立验证商户免税资格。合计不一致时会提示核对优惠、漏项和重复项，不会偷偷调平。可选票面消费时间经过严格本地日期格式校验，不用当前时间填补未知年份。分类和时间细节见 [AI_RECOGNITION.md](AI_RECOGNITION.md)，政策说明见 [TAX_POLICY.md](TAX_POLICY.md)。

## 开源维护要求

不要提交真实 API Key、用户小票、账本备份、签名私钥或含个人信息的调试输出。提交安全问题时使用合成票据、占位密钥和最小复现；复现网络问题时不要附带 Authorization 请求头。任何新增联网功能、SDK、备份范围或图片持久化变更都需要同时更新本文件及对应测试。
