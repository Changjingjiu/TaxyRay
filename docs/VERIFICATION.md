# 0.2.0 发行验证

验证日期 2026-09-15。使用完整 JDK 17、Android SDK 35 和专用 Android 16 / API 36 ARM64 模拟器。已连接的用户手机没有安装、卸载、清空或运行测试。历史记录见 [0.1.1](VERIFICATION-0.1.1.md)。

## 构建与算法

最终 Debug、R8 Release、AndroidTest 构建成功。Debug 和 Release lint 均为 **0 errors / 27 warnings**，主要为固定依赖可升级、targetSdk 和 KTX 建议，以及为安装会话持久化使用同步 commit 的提示，没有新增忽略规则。

**84 项 JVM 测试全部通过**：核心算法16、草稿3、备份11、端点7、AI服务10、解析25、更新元数据与身份5、更新网络7。金额算法没有改为浮点数，整单仍按逐项舍入后相加。

AI 使用合成 10 项、99.91 元案例覆盖发酵乳和馅饼归类，以及普通服务6%、免税证据、金额对账和票面时间。新增不同时区下的时间戳上下界检查。模型输出协议的模拟测试不等于真实照片识别准确率；本轮没有上传用户小票或复用真实密钥。

## 仍需真机覆盖

Android 8–9 的系统文件保存、不同厂商的安装/相册/分享流程、物理震动手感、长票低光褶皱图片的模型表现，仍需按设备实测。没有宣称达到原始需求中的冷启动、写入或图像处理性能指标，也没有声称已发布应用商店版本。
