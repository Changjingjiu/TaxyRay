# 0.1.0 本地交付验证

验证日期：2026-09-15。平台为 macOS ARM64 + 完整 JDK17 + Android SDK35；设备测试使用 Android16 / API36 ARM64 模拟器。没有访问真实 API Key，没有上传真实小票。

## 构建与静态检查

以下同一轮构建成功：

```sh
./gradlew :core:test :app:testDebugUnitTest :app:lintDebug :app:lintRelease :app:assembleDebug :app:assembleRelease
```

- debug、R8 release 均构建成功。
- debug/release lint 均为 **0 errors、20 warnings**。警告主要是存在更新版依赖、按要求保留targetSdk35，以及KTX/版本检查建议；没有隐藏lint错误或新增baseline豁免。
- Gradle8.13构建成功；存在Gradle9迁移相关弃用提示，因此不宣称兼容尚未验证的Gradle9。
- 交付预览 APK 是 R8 release 产物，使用本机开发测试证书签名；不是项目最终发行证书。APK签名检查及 `zipalign -c -P 16` 检查通过。
- 预览 APK 在模拟器安装、冷启动、手动录入113.00与13%计税、显示13.00税额均成功。一次`am start -W`记录TotalTime609ms，仅是该模拟器单次观测，不是受控真机基准。

## 图像与布局

- 检查了手机浅色、手机深色+130%字体，以及模拟器覆盖1800×2560/density280的宽屏布局。宽屏使用导航轨道；测试后恢复默认手机尺寸、密度、字体和浅色设置。这不是物理平板验收。
- 三项合成账单：`113@13% + 109@9% + 20@0%`，实付242.00、税前220.00、税额22.00、有效占比9.09%。
- 纸本、松石绿两套真实PNG均为 **986×1729**；纸本168,701字节，松石绿169,361字节。对图片实际解码，验证不是空图/纯色图、背景不透明、完整卡片高度、模板差异与末尾摘要可见。
- 已肉眼检查导出金额、三档构成及“非发票、非完税证明”说明。截图含QA测试商户，不是用户真实账本，也不会预装进APK。
- 出票顶部裁剪、税率共享滑块、估算章落定后才允许导出均包含在最终UI测试代码中。触觉调用系统接口，模拟器无法确认实体手感。

## 尚未验证的部分

没有真机验收、真实付费视觉模型端到端识别、不同厂商相机/分享行为、Android8–9的SAF图片保存实机验证或性能基准。不能据此承诺冷启动<800ms、写入<50ms、压缩<500ms在所有设备达标。未测试正式发行证书的升级链路，也未推送GitHub或运行远端CI。

算法仅用于用户确认税率后的数学估算，测试通过不等于对销售方税务身份、免税资格或实际缴税额作出认定。备份单文件导入/导出为5MB、10,000单、每单1000项的明确上限，超限会拒绝，当前不支持分卷。
